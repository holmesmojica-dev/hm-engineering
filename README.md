# HM Engineering

HM Engineering is the central engineering knowledge base for the HM ecosystem.

It provides the shared specifications, architectural guidance, engineering standards, and technical decisions used across HM projects.

Unlike other HM repositories, this project does not contain source code. Instead, it defines the concepts, principles, and engineering practices that guide the design and implementation of the HM ecosystem.

## Repository Structure

```text
docs/
├── domains/
├── architecture/
├── standards/
└── adr/
```

### Domains

Canonical domain specifications shared across HM projects.

### Architecture

Architecture documentation, design principles, and ecosystem-level guidance.

### Standards

Development standards, project templates, conventions, and best practices.

### ADR

Architecture Decision Records documenting important engineering decisions and their rationale.

## Engineering Philosophy

HM Engineering follows a simple principle:

> **The domain is the source of truth. Implementations represent the domain but do not define it.**
